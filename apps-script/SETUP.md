# GAS Web App セットアップ手順

これはGoogleアカウントでの操作が必要なため、ユーザー自身で行う手順です。

## 1. スプレッドシートを作成

1. https://sheets.new を開く(新規スプレッドシートが作成される)
2. わかりやすい名前に変更する(例: 「筋トレ記録」)

## 2. Apps Scriptプロジェクトを紐付け

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
2. デフォルトで開かれる `コード.gs` の中身を全て削除し、このリポジトリの
   [`Code.gs`](Code.gs) の中身を丸ごと貼り付ける
3. 上部の保存アイコンで保存

## 3. シートを初期化する

1. Apps Scriptエディタの関数選択ドロップダウンから `setup` を選ぶ
2. 実行ボタン(▶)を押す
3. 初回は権限承認画面が出るので、自分のGoogleアカウントで許可する
   (「このアプリはGoogleで確認されていません」と出た場合は「詳細」→
   「(プロジェクト名)に移動」で進める。自分が作ったスクリプトなので問題ない)
4. 実行後、スプレッドシートに4つのシート(種目マスタ / トレーニングログ /
   体組成ログ / 長期メニュー)が作られていればOK

## 4. シークレットトークンを設定

1. Apps Scriptエディタ左側の歯車アイコン「プロジェクトの設定」を開く
2. 「スクリプト プロパティ」→「スクリプト プロパティを追加」
3. プロパティ: `SECRET` / 値: 好きなランダム文字列(例: パスワード生成ツールで
   作った32文字程度の英数字)を入力して保存
   - この値は後でフロントエンド側の設定画面にも入力する。忘れないよう控えておく

## 5. Webアプリとしてデプロイ

1. Apps Scriptエディタ右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択(歯車アイコン)で「ウェブアプリ」を選択
3. 設定:
   - 説明: 任意(例: v1)
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
     (匿名アクセス可能になるが、SECRETトークンを知らないと読み書きできないので実質保護される)
4. 「デプロイ」をクリックし、権限承認が出たら許可
5. 発行された「ウェブアプリのURL」(`https://script.google.com/macros/s/xxxx/exec`)
   をコピーして控えておく

## 6. 動作確認

ブラウザで `<ウェブアプリのURL>?action=ping` を開き、以下のようなJSONが
返ってくれば成功:

```json
{"ok":true,"message":"muscle-training-app GAS is alive"}
```

## 7. フロントエンドに設定

アプリの「設定」タブで、5でコピーしたURLと4で設定したSECRETを入力する。
入力値はブラウザのlocalStorageに保存され、以後の記録・グラフ表示に使われる。

## スクリプトを更新したとき

`Code.gs` の中身を修正した場合は、Apps Scriptエディタ側のコードも貼り替えた上で、
「デプロイ」→「デプロイを管理」→ 既存デプロイの鉛筆アイコン→
バージョン「新バージョン」を選んで「デプロイ」を押す(URLは変わらない)。

## シート構成が変わったとき(週間メニュー→長期メニュー)

以前のバージョンで作成したスプレッドシートには「週間メニュー」シート(曜日のみで
週数の概念がない)が残っている場合がある。まだメニューデータを入れていなければ、
以下のどちらかで対応する。

- スプレッドシート下部のシートタブで「週間メニュー」を右クリック→削除し、
  Apps Scriptエディタで `setup` 関数を再実行する(「長期メニュー」シートが
  新しいヘッダー付きで作られる)
- または「週間メニュー」タブ名を「長期メニュー」に変更し、1行目のヘッダーを
  手動で `週, 曜日, 種目名, 目標セット, 目標回数, 目標重量, メモ` に直接打ち直す
