# 筋トレ進捗管理アプリ

スマホのブラウザで使う、個人用の筋トレ記録アプリ。トレーニングログ・体重体脂肪率は
Googleスプレッドシートにリアルタイム同期される。メニュー作成はアプリ自身が考えるのではなく、
プロフィールから相談用プロンプトを組み立て、Claudeとの会話で決めたメニューをJSONでインポートする。

## 構成

- [`index.html`](index.html) — フロントエンド本体(単一HTMLファイル)。GitHub Pagesで公開する。
- [`apps-script/Code.gs`](apps-script/Code.gs) — データ保存先のGoogleスプレッドシートに紐付けるGAS Web Appのコード。
- [`apps-script/SETUP.md`](apps-script/SETUP.md) — スプレッドシート作成〜GAS Web Appデプロイまでの手順(Googleアカウントでの操作が必要なため手動)。

## セットアップの流れ

1. [`apps-script/SETUP.md`](apps-script/SETUP.md) の手順に沿って、Googleスプレッドシート
   と GAS Web App を用意する。最後に「Web AppのURL」と「SECRET(シークレットトークン)」が手元に残る。
2. `index.html` を GitHub Pages で公開する(リポジトリのPages設定を有効化)。
3. 公開されたアプリを開き、「設定」タブに1で控えたURLとSECRETを入力して保存。
   「接続テスト」で `接続成功` と表示されればOK。
4. 「記録」タブでトレーニング、「体重」タブで体組成を記録できる。「グラフ」タブで推移を確認できる。
5. 「プロフィール」タブで目標などを入力し、「相談用プロンプトを作る」→「コピーする」で
   Claudeとの別会話に貼り付けてメニューを相談する。返ってきたJSONを「メニュー」タブの
   インポート欄に貼り付けると長期メニューに反映される。

## メニューインポートのJSON形式

長期メニューは「週番号 × 曜日」で構成する(毎週同じ内容を繰り返す週間メニューではなく、
目標達成の期限までを複数週に分け、週が進むごとに重量やボリュームを変化させる想定)。

```json
[
  { "week": 1, "day": "月", "exercise": "ベンチプレス", "sets": 4, "reps": "8-10", "weight": "60kg目安", "memo": "" }
]
```

- `week` は 1 始まりの週番号(数値)
- `day` は `月・火・水・木・金・土・日` のいずれか(休養日の行は不要)
- `reps` / `weight` は幅を持たせた文字列でもよい
- インポートすると既存の長期メニューは全て置き換わる

## データはどこにあるか

すべてのトレーニングログ・体組成ログ・種目マスタ・長期メニューは、セットアップ時に作成した
Googleスプレッドシートに保存される。PCからもExcel感覚でそのまま閲覧・編集できる。
プロフィール入力と接続設定(URL/SECRET)だけは、ブラウザの localStorage に保存される
(端末・ブラウザごとに個別)。
